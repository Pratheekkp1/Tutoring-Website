# AcePrep: Tutoring Website

Marketing and registration site for **AcePrep**, a tutoring service for SAT, PSAT and AP courses.

## Features

- Responsive single-page layout: hero, why-choose-us, tutor profiles and contact sections
- Mobile navigation menu and scroll-aware header
- **Registration / inquiry form wired to Google Sheets.** Submissions POST to a Google Apps Script web app that appends each lead to a spreadsheet the business already uses. No server to maintain.

## Tech

HTML5 · CSS3 · vanilla JavaScript · Google Apps Script

## Run

Open `index.html` in a browser, or serve the folder with any static host.
